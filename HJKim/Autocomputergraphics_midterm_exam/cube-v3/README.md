# cube-v3

cube-v2r1을 복사해서 **월드 기준선**과 **관찰자 뷰**를 추가한 버전입니다. cube-v2r1은 그대로 두고 이 폴더에서만 수정합니다.

cube-v2r1에도 월드 좌표계 기준 오빗 카메라가 있었지만, 화면에 큐브 하나와 검은 배경뿐이라 카메라를 돌린 것과 물체를 돌린 것이 똑같아 보였습니다. 이 버전은 월드에 고정된 격자와 축을 그리고, 메인 카메라 자체를 바깥에서 보여주는 두 번째 카메라를 추가해서 좌표계와 시점 변화를 눈으로 확인할 수 있게 했습니다.

## 추가한 기능

| 기능 | 사용한 기능 | 코드 위치 |
|---|---|---|
| 월드 x-z 평면 격자 (-10 ~ 10, 5칸마다 진하게) | `GL_LINES`, 색만 칠하는 셰이더 | `LineGeometry::grid()`, `line_vshader.glsl`, `line_fshader.glsl` |
| 월드 축 (+ 방향 진하게, - 방향 흐리게) | 월드 좌표로 만든 선, 모델 행렬 = 단위 행렬 | `LineGeometry::worldAxes()` |
| 물체 축 | 같은 단위 축을 물체의 모델 행렬 `Mo = To × Ro`로 배치 | `MainWidget::drawScene()` |
| 카메라가 바라보는 점 (흰 별표) | `translate(cameraTarget)` | `MainWidget::drawScene()` |
| 관찰자 뷰: 메인 카메라를 바깥에서 보는 두 번째 카메라 (작은 창 / 화면 반 나누기) | `glViewport`, `glScissor`. 같은 장면을 view, projection만 바꿔서 두 번 그림 | `paintGL()`, `mainViewport()`, `observerViewport()` |
| 메인 카메라의 시야 범위(view frustum) | NDC 큐브 [-1, 1]³을 `(P × V)⁻¹`로 월드에 되돌림 | `MainWidget::drawScene()` |
| 메인 카메라 좌표계와 눈~near 구간 | 카메라 좌표로 만든 선을 `V⁻¹`(카메라 → 월드)로 배치 | `MainWidget::drawScene()` |
| 시야각(FOV), near, far 조절 | `QMatrix4x4::perspective` | `MainWidget::setProjection()` |
| 뷰 제목 글씨 | `paintGL()` 안에서 `QPainter` 사용 | `MainWidget::paintLabels()` |
| 기준선 켜기/끄기, 관찰자 뷰 구성과 오빗 값 | 패널 그룹 2개 추가. 기존 양방향 연동(`sceneChanged()` → `showState()`) 그대로 사용 | `controlpanel.cpp` |

## 화면에 보이는 것

| 표시 | 의미 |
|---|---|
| 회색 격자 | 월드 x-z 평면 (y = 0). 큐브 중심을 지나므로 큐브를 가로지릅니다 |
| 빨강 / 초록 / 파랑 | X / Y / Z 축. 월드 축은 + 방향이 진하고 - 방향이 흐립니다 |
| 큐브 중심에서 나온 짧은 축 | 물체 좌표계. 큐브에 가려지지 않게 항상 위에 그립니다 |
| 흰 별표 | 메인 카메라가 바라보는 점 (`cameraTarget`) |
| 노란 상자 (관찰자 뷰) | 메인 카메라의 시야 범위. 앞쪽 작은 면이 near 평면, 뒤쪽 큰 면이 far 평면 |
| 회색 선 (관찰자 뷰) | 카메라 눈에서 near 평면 모서리까지. 이 구간에 있는 것은 메인 카메라에 그려지지 않습니다 |
| 카메라 위치의 작은 축 (관찰자 뷰) | 메인 카메라 좌표계. 카메라는 -z 방향을 보므로 파란 z축이 시선 반대쪽을 향합니다 |

## 조작 방법

키보드는 3D 화면을 한 번 클릭한 뒤 동작합니다.

| 입력 | 동작 |
|---|---|
| 왼쪽 드래그 | 물체 회전 (cube-v2와 같음) |
| 오른쪽 드래그, Shift + 왼쪽 드래그, 방향키 | 카메라 오빗 |
| 휠 | 확대/축소 (카메라와 바라보는 점 사이 거리) |
| W / S, A / D, Q / E | 카메라 앞/뒤, 왼쪽/오른쪽, 아래/위 이동 |
| **관찰자 뷰 안에서 드래그** (아무 버튼) | 관찰자 카메라 오빗 (월드 원점 기준) |
| **관찰자 뷰 안에서 휠** | 관찰자 확대/축소 |
| **V** | 관찰자 뷰: 끄기 → 작은 창 → 화면 반 나누기 |
| Space | 자동 회전 켜기/끄기 |
| R | 초기화 |

드래그는 누르기 시작한 곳의 뷰가 받습니다. 작은 창 안에서 시작한 드래그는 창 밖으로 나가도 관찰자 카메라를 움직입니다.

### 해볼 만한 것

- **far를 줄이거나 휠로 멀어지기**: 큐브가 노란 상자 밖으로 나가는 순간 메인 뷰에서 잘립니다.
- **near를 3, far를 7로 설정** (cube-v2의 원래 값): 시야 범위가 큐브를 딱 감쌉니다.
- **시야각(FOV) 바꾸기**: 노란 상자가 넓어지거나 좁아지고, 메인 뷰의 원근감이 바뀝니다.
- **왼쪽 드래그와 오른쪽 드래그 비교**: 왼쪽 드래그는 물체 축만 돌고, 오른쪽 드래그는 관찰자 뷰에서 카메라가 원을 그리며 움직입니다.
- **WASD**: 흰 별표(바라보는 점)와 카메라가 함께 평행 이동합니다.

## 구현 메모

- **시야 범위 = NDC 큐브의 역변환**: 투영 × 뷰 행렬 `P × V`는 시야 범위를 NDC 큐브 [-1, 1]³로 보냅니다. 그래서 큐브의 모서리 12개를 `(P × V)⁻¹`로 변환하면 시야 범위가 됩니다. 관찰자 뷰에서는 `mvp = P_관찰자 × V_관찰자 × (P × V)⁻¹`로 그립니다. 역변환 결과는 w ≠ 1인 동차 좌표지만, GPU가 클립 좌표를 w로 나누기 때문에 따로 나눌 필요가 없습니다. 시야 범위 안의 점은 w > 0이라 이 방법이 성립합니다.
- **카메라 모형 = V⁻¹**: 뷰 행렬 V는 월드 → 카메라 좌표 변환입니다. 그 역행렬은 카메라 좌표(눈이 원점, -z 방향을 봄)로 만든 선을 월드에 놓습니다. 눈~near 구간은 단위 피라미드를 `(near·tan(fov/2)·aspect, near·tan(fov/2), near)`로 늘려서 그립니다.
- **같은 위치에 그린 선과 면(z-fighting)**: 두 도형이 같은 위치에 있으면 깊이 값이 거의 같아서 깜빡입니다. 이 버전에서는 네 군데를 피했습니다.
  - 격자 중앙선은 월드 x, z축과 겹치므로 빼고 그립니다.
  - 물체 축과 카메라 축은 월드 축과 겹칠 수 있어서 깊이 테스트를 끄고 마지막에 그립니다.
  - 기본 자세의 큐브 면(x, z = ±1)은 격자선과 겹치므로 `glPolygonOffset`으로 면을 살짝 앞으로 당깁니다.
  - 바라보는 점 표시는 축과 겹치지 않게 + 모양 대신 대각선 별표로 그립니다.
- **Retina 화면**: 위젯 좌표는 논리 픽셀이고 y가 아래로 갑니다. `glViewport`는 장치 픽셀이고 y가 위로 갑니다. 그래서 `setGLViewport()`에서 `devicePixelRatioF()`를 곱하고 y를 뒤집습니다.
- **관찰자 뷰만 지우기**: 작은 창 영역만 `glScissor` + `glClear`로 지운 뒤 그 안에 관찰자 시점으로 다시 그립니다.

## 파일 구성 (cube-v2r1 대비)

| 파일 | 상태 | 내용 |
|---|---|---|
| `linegeometry.h/.cpp` | 새 파일 | 정점마다 색이 있는 선분(VAO + VBO)과 격자, 축, 상자, 피라미드, 별표 정점 생성 함수 |
| `line_vshader.glsl`, `line_fshader.glsl` | 새 파일 | 선 전용 셰이더 (텍스처 없이 정점 색) |
| `scenestate.h` | 수정 | 투영(FOV, near, far), 기준선 표시, 관찰자 카메라 값, `ObserverMode`, `orbitOffset()` 추가 |
| `mainwidget.h/.cpp` | 수정 | 그리기를 `drawScene(view, projection)`으로 분리해 두 뷰에서 호출. 뷰포트 계산, 입력을 누른 뷰로 분기, 뷰 제목 |
| `controlpanel.h/.cpp` | 수정 | 카메라 그룹에 FOV, near, far. "관찰자 뷰", "기준선 표시" 그룹 추가 |
| `mainwindow.cpp` | 수정 | 새 signal/slot 연결 |
| `CMakeLists.txt`, `CMakePresets.json`, `cube.pro`, `shaders.qrc`, `main.cpp` | 수정 | 새 파일 추가, 대상 이름을 `cube-v3`로 변경 |
| `geometryengine.*`, `fshader.glsl`, `vshader.glsl`, `cube.png`, `textures.qrc`, `mainwindow.h` | 그대로 | cube-v2r1과 같음 |

## cube-v2r1에서 달라진 동작

- **투영 범위 기본값**: near 0.1 / far 100 → near 0.5 / far 20. 관찰자 뷰에서 시야 범위 전체가 보이는 크기입니다. 그 대신 카메라 거리가 약 18보다 멀어지면 큐브가 far 평면에 잘립니다. 패널에서 near 0.1 ~ 10, far 2 ~ 200으로 바꿀 수 있고, far는 항상 near보다 1 이상 뒤에 있도록 제한합니다.
- **투영 행렬 계산 위치**: `resizeGL()`이 아니라 매 프레임 `projectionMatrix()`에서 계산합니다. 화면 반 나누기 모드에서는 메인 뷰의 가로세로 비율이 달라지고, FOV, near, far를 패널에서 바꿀 수 있기 때문입니다.
- **초기화(R)**: 물체와 카메라에 더해 관찰자 카메라 위치도 처음으로 돌아갑니다. 투영, 기준선 표시, 관찰자 화면 구성은 자동 회전 설정처럼 그대로 둡니다.
- **기본 화면**: 시작하면 관찰자 뷰가 오른쪽 아래 작은 창으로 켜져 있습니다. V 키나 패널에서 끌 수 있습니다.
- **처음 시점에서 격자**: 메인 카메라의 처음 위치는 cube-v2와 같아서(고도각 0) x-z 평면을 옆에서 봅니다. 그래서 격자가 가로선 하나로 보입니다. 방향키 ↑나 오른쪽 드래그로 카메라를 올리면 격자가 보입니다.

## 빌드

- **macOS**: `CMakeUserPresets.json`의 `macos` 프리셋을 씁니다(Apple Clang, Ninja, Homebrew Qt).
- **Windows**: `CMakePresets.json`의 `msvc2022-x64` 프리셋을 씁니다. Windows/MSVC 빌드는 직접 확인하지 않았습니다.
