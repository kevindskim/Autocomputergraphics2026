# cube-final

Qt OpenGL 주사위 큐브 예제([kevindskim/Autocomputergraphics2026](https://github.com/kevindskim/Autocomputergraphics2026)의 cube-v2)를 바탕으로 기능을 추가한 프로젝트입니다.

## 개발 환경

- Qt 6.10.2 (msvc2022_64), OpenGL 3.3 Core Profile
- MSVC 2022, CMake 3.25 이상
- VSCode + CMake Tools 확장

## 빌드와 실행

1. `CMakePresets.json`의 Qt 경로(`C:/Qt/6.10.2/msvc2022_64`, 3곳)를 자신의 Qt 설치 경로로 바꿉니다.
2. VSCode에서 이 폴더를 열고 Configure Preset `MSVC 2022 x64`, Build Preset `Build Debug`를 고릅니다.
3. `F7`로 빌드하고, 상태 표시줄의 실행 버튼(또는 `Shift + F5`)으로 실행합니다.

명령줄에서는 다음과 같이 빌드합니다.

```
cmake --preset msvc2022-x64
cmake --build --preset build-debug
```

## 추가한 기능

| 기능 | 설명 |
| --- | --- |
| 메뉴 바와 상태 표시줄 | 파일 · 보기 · 조명 · 도움말 메뉴, 상태 메시지 표시 |
| 설정 창 (F2) | 도형, 시야각, 시점, 조명을 한 곳에서 변경 |
| 도형 바꾸기 | 정육면체 주사위(D6), 정사면체(D4), 정팔면체(D8), 정이십면체(D20). 꼭짓점 좌표로 면을 자동 생성하고, 마주 보는 면의 합이 N+1이 되도록 번호를 붙임 |
| 숫자 텍스처 생성 | QPainter로 숫자 텍스처 아틀라스를 직접 그려 각 면에 매핑 |
| 주사위 시점 (V) | 주사위 1번 면의 눈으로 장면을 봄. 원래 카메라는 노란 카메라 모델로 표시 |
| Phong 조명 | 정점 법선 추가, ambient + diffuse + specular, 광원 이동과 광원 색 변경 |
| 카메라 조작 | 공전, 상하 회전, 거리 조절, 시야각(광각 ↔ 망원), 원근/직교 투영 전환 |
| 카메라 이동 모드 (C) | 주사위와 바닥은 고정하고 카메라만 주사위 주위를 돎 |
| 면 보기 (숫자 키) | 해당 번호의 면이 카메라를 향하도록 쿼터니언 slerp로 회전 |
| 관성 회전 | 드래그를 놓은 뒤에도 감속하며 계속 회전 |
| 바닥 격자와 좌표축 | world 축과 object 축을 함께 표시 |

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 왼쪽 드래그 | 주사위 회전 (C 모드: 카메라 공전, 주사위 시점: 둘러보기) |
| 마우스 휠 / Ctrl + 휠 | 카메라 거리 / 시야각 |
| 방향키 | 드래그와 같은 동작을 5°씩 |
| A / D, Q / E | 카메라 좌우 / 상하 회전 |
| W / S | 카메라 가까이 / 멀리 |
| Z / X | 시야각 넓게(광각) / 좁게(망원) |
| J / K | 광원 이동 |
| 숫자 키 | 해당 번호의 면을 카메라 쪽으로 (두 자리는 빠르게 이어서 입력, 예: 1 → 2 = 12) |
| C / V | 카메라 이동 모드 / 주사위 시점 |
| L / P / R | 조명 켜기·끄기 / 원근·직교 투영 / 초기화 |
| F2 | 설정 창 |

## 스크린샷 자동 생성

같은 장면을 다시 만들 수 있도록 실행 옵션을 지원합니다.

```
cube-final --shape 3 --die-view --face 1 --grab shot.png
```

`--shape`는 0 = D6, 1 = D4, 2 = D8, 3 = D20입니다.

키 입력을 순서대로 실행하며 매 프레임(25 fps)을 저장해 영상으로 만들 수도 있습니다.

```
cube-final --size 960x720 --script "C,Right*72" --record frames
```

`--script`의 각 단계는 키 이름(`D`, `Left`, `L` 등), `wait`, `shape=N`, `color=N` 중 하나이고 `*횟수`로 반복합니다.
